## ✨ About Project

🔥 **Spotify Clone** is a **modern frontend developer project** inspired by Spotify.

It delivers a **premium UI, smooth animations, and responsive design**  
to create a real-world music web app experience.

💡 This project showcases:
- 🎯 UI/UX Design Skills  
- ⚡ Advanced CSS Animations  
- 🎵 Audio Player Functionality  
- 📱 Fully Responsive Layout  

---

## 🌟 Features

- 🎧 Play / Pause functionality  
- 🎼 Custom audio player  
- 🎨 Modern dark UI  
- 📱 Fully responsive design  
- ⚡ Smooth animations & hover effects  
- 🔥 Interactive playlist cards  
- 🎯 Clean Spotify-like layout  

---

## 🎬 Animations & Effects

- 💫 Hover transitions  
- 🎯 Card zoom + shadow effects  
- ⚡ Smooth scrolling animations  
- 🎵 Animated progress bar  
- 🌊 Wavy animated header
